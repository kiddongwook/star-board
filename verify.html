지키는 원칙

Rules we keep

  • 판정은 돈으로 살 수 없어요. 결과가 좋지 않으면 공개 여부는 의뢰하신 분이 정하고, 공개하면 판정은 그대로 나가요.
  • The verdict is not for sale. If the result is weak, you decide whether it is published; if it is, the verdict stays as it is.
  • 의뢰받은 검증은 영상과 페이지에 "의뢰 검증"이라고 표시해요.
  • Commissioned checks are labelled "commissioned" in the video and on the page.
  • 우리가 실제로 돌린 결과만 보여 줘요. API 키나 유료 계정이 필요한 부분은 README·공식 데모 기반이라고 밝혀요.
  • We only show what we ran. Parts that need API keys or paid accounts are marked as README/official-demo based.
  • 격리 실행: 낯선 코드는 비밀값이 없는 별도 환경에서만 실행해요.
  • Isolated runs: unfamiliar code only runs in a separate environment with no secrets.

진행 순서

How it works

  1. 이메일로 저장소 링크와 검증받고 싶은 기능(한두 가지)을 보내 주세요.
  2. Email us your repo link and the one or two things you want checked.
  3. 실행 가능 여부를 보고 회신드려요. 키나 장치가 필요한 경우 검증 범위를 먼저 맞춰요.
  4. We check that it can run and reply. If keys or hardware are needed, we agree on the scope first.
  5. 실행 → 숫자 측정 → 판정 → 쇼츠 제작.
  6. Run → measure → verdict → Short.
  7. 결과를 먼저 보내 드리고, 공개 후 페이지와 배지를 드려요.
  8. You see the result first; after publishing you get the page and the badge.

가격: 파일럿 진행 중이에요. 이메일로 문의해 주세요.

Pricing: pilot in progress. Ask by email.
